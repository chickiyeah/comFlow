# 채용 키워드 프로필·적합도 설계

## 목표

채용공고 검색을 단일 문자열 매칭에서 직무 프로필 기반 검색으로 확장한다. `백엔드`, `AI`, `AX`, `인프라`, `DevOps` 등의 입력을 동의어·기술어·업무어로 확장하고, 각 공고에 직무 적합도와 신입~2년 적합도를 계산한다.

## 범위

- 검색 프로필: backend, ai, ax, infra, devops, data, security
- 프로필별 포함어·제외어·가중치 정의
- 수집 결과 URL 중복 제거
- 제목·회사명·지역·직무형태·급여·저장 키워드에서 매칭어 계산
- 경력 표현(`신입`, `경력무관`, `1~2년`, `3년 이상`, `경력직`) 분석
- 기존 검색 API의 요청 형식과 기존 결과 필드는 유지
- 결과에 선택적 적합도 메타데이터 추가

## 결과 계약

기존 `JobSearchResult` 필드는 유지한다. 다음 필드를 추가한다.

- `profile`: 적용된 직무 프로필
- `matchedTerms`: 매칭된 확장 키워드 목록
- `fitScore`: 0~100 종합 적합도
- `experienceFitScore`: 신입~2년 적합도 0~100

기존 소스 실시간 검색 결과에는 프로필이 없을 수 있으므로 기본값은 `null`, 빈 목록, `0`으로 허용한다. imported 검색과 프로필 검색 경로에서는 계산된 값을 제공한다.

## 점수 규칙

- 포함어 매칭: 제목 10점, 회사명 4점, 직무형태·급여·지역 2점
- 프로필 핵심어 보너스: 10점
- 제외어 매칭: 항목당 15점 감점
- 신입/경력 적합도: 신입·경력무관 +40, 1~2년 +35, 연차 미표기 +20, 3년 이상 -35, 경력직 -30
- 점수는 0~100으로 제한한다.

## 오류 및 호환성

- 빈 키워드는 기존 전체 검색 동작을 유지한다.
- 알 수 없는 프로필은 기존 문자열 검색으로 처리한다.
- 마감일은 기존 `deadline` 값을 그대로 사용하며 생성일을 마감일로 대체하지 않는다.
- 한 소스 실패는 다른 소스 결과를 차단하지 않는다.

## 검증

- 프로필 동의어 확장과 제외어 필터 단위 테스트
- 경력 표현별 점수 단위 테스트
- 동일 URL 중복 제거 테스트
- 기존 JobImportService 및 JobSearchController 테스트 회귀 실행
- Maven 전체 테스트 실행
