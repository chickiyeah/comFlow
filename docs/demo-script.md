>

> **진로 페이지 탭**: `4학기 학습 로드맵` · `JobPilot` · `취업 통계` · `취업 준비` · `채용 검색` · `추천 자격증` · `채용 알리미`

- **자막**:
  - (큰 제목) `CampusFlow`
  - (부제) `AI 기반 통합 학사·취업 지원 플랫폼`
  - (하단) `공학계열 · 팀명 나경완 · 이여울 · 등근 | 전주비전대학교`
- **내레이션**:

## ① 대시보드 — 한 화면에 모은 학사 현황 (약 25초)
- **클릭 시나리오**:
  1. 로그인 화면에서 학생 계정으로 로그인
  2. 대시보드 진입 → 마우스로 **GPA · 이수 학점 · 출결률 · 졸업요건** 카드를 천천히 훑기
- **자막**: `① 흩어진 학사 정보를 한 화면에`
- **내레이션**:
  > "로그인하면 첫 화면에서 학점과 이수 학점, 출결률, 졸업 요건까지 한눈에 확인할 수 있습니다. 여러 시스템을 돌아다닐 필요 없이, 내 학사 현황이 한 화면에 모입니다."

---

## ② AI 학생 어드바이저 — 내 데이터를 분석 (약 30초)
- **클릭 시나리오**:
  1. 화면 **우측 하단(또는 좌측 하단) 플로팅 버튼**으로 AI 어시스턴트 패널 열기 → **분석 실행**
  2. 결과 스크롤: **종합 조언 → 추천 자격증 → 포트폴리오 아이디어** 순서로 보여주기
- **자막**: `② 내 성적·출결을 분석하는 AI 어드바이저`
- **내레이션**:
  > "AI 학생 어드바이저는 내 성적과 출결 데이터를 분석해, 다음 학기에 집중할 과목과 추천 자격증, 포트폴리오 아이디어까지 제안합니다. 데이터를 입력하는 게 아니라, 내 데이터로 맞춤 조언을 받습니다."

---

## ③ 실시간 채용공고 — 통합 검색 · 마감 필터 (약 30초)
- **클릭 시나리오**:
  1. **진로** 메뉴 → **채용 검색** 탭
  2. 키워드 입력(예: `백엔드`) → 검색
  3. **'마감 지난 공고 숨기기'** 토글을 껐다 켜서 결과가 줄어드는 것 보여주기
  4. 출처 칩에서 **'실시간수집'** 클릭 → 자동 수집된 공고 보여주기
- **자막**: `③ 여러 사이트를 실시간 통합 · 마감 공고 자동 제외`
- **내레이션**:
  > "취업 메뉴에서는 고용24, 잡코리아 같은 여러 채용 사이트의 공고를 실시간으로 통합 검색합니다. 마감이 지난 공고는 필터로 자동 제외되고, 백그라운드로 수집된 최신 공고도 함께 볼 수 있습니다."

---

## ④ AI 자소서 생성 (JobPilot) — 핵심 기능 ⭐ (약 50초)
- **클릭 시나리오**:
  1. **진로** 메뉴 → **JobPilot** 탭
  2. **1단계(공고 입력)**: 채용공고 본문을 붙여넣기 → **추출하기**
  3. **2단계**: 자동 추출된 회사·직무·자소서 문항 확인(필요 시 수정)
  4. **3단계**: **강·약점 분석** → 강점/보완필요 배지 보여주기
  5. **4단계**: **자소서 생성** → 문항별 본문 + **실시간 글자 수(공백포함/제외)** 배지 스크롤
- **자막**: `④ 채용공고 → 직무 맞춤 자소서 자동 생성 (없는 경험은 지어내지 않음)`
- **내레이션**:
  > "핵심 기능인 AI 자소서 생성입니다. 지원하려는 채용공고를 붙여넣으면, AI가 회사와 직무, 자기소개서 문항을 자동으로 추출합니다. 이어서 내 프로필과 대조해 강점과 약점을 분석하고, 그 결과를 바탕으로 문항별 맞춤 자소서를 작성합니다. 글자 수 제한도 실시간으로 맞추고, 무엇보다 내 프로필에 없는 경험은 지어내지 않습니다. 정직성을 지키는 자소서 생성입니다."

## ⑤ AI 취업 로드맵 (약 20초)
- **클릭 시나리오**:
  1. **진로** 메뉴 → **4학기 학습 로드맵** 탭
  2. 희망 직무 입력(예: `백엔드 개발자`) → **생성**
  3. **학기별 학습 계획 + 추천 자격증** 결과 보여주기
- **자막**: `⑤ 학과 자료 기반 AI 취업 로드맵`
- **내레이션**:
  > "AI 취업 로드맵은 희망 직무를 입력하면, 학과 자료를 근거로 학기별 학습 계획과 필요한 자격증을 제시합니다."
