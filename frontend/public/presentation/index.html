왜 만들었나

2년 안에 학업과 취업을
동시에 준비해야 하는 학생들

TARGET

전문대 컴퓨터정보과

4학기라는 짧은 시간 안에 학점과 커리어를 함께 쌓아야 하는 학생.

PROBLEM

정보가 제각각

성적·출결·포트폴리오·자격증·취업 정보가 흩어져 있고, 어디서부터 시작할지 막막함.

SOLUTION

데이터 + AI

학생 한 명의 데이터를 모아 AI가 분석하고, 맞춤 로드맵과 실전 도구를 제공.

핵심 가치

세 가지를 약속합니다

01

AI가 "나만의" 진로를 설계

희망 직무만 입력하면 2년 학습 로드맵·자격증·자소서·모의면접까지 한 번에.

담당 AI · 나경원
02

학생 데이터 기반 맞춤 분석

성적·출결·졸업요건을 AI 어드바이저가 읽고 약점과 다음 행동을 짚어줌.

담당 백엔드·데이터 · 나경원·이의성
03

실제 쓸 수 있는 완성도

5개 국어 다국어, 다크모드, 모바일 대응까지 갖춘 실서비스 수준 UX.

담당 프론트엔드·UX · 돌군
메인 화면

첫 화면이 곧 AI 챗봇

CampusFlow는 복잡한 메뉴가 아니라 AI 프롬프트 창으로 시작합니다. 학과·진로·자격증·취업 무엇이든 물어보면, 학과 자료를 학습한 AI(RAG)가 바로 답합니다.

01

로그인 없이 즉시 질문

게스트도 바로 채팅 — 대화는 기기에 7일간 보관, 추천 질문도 제공.

02

학과 자료 기반 답변

교육과정·자격증·취업 정보를 학습한 RAG가 근거 있는 답변을 생성.

03

로그인하면 영구 저장

대화 기록을 계정에 저장하고 여러 세션으로 이어서 사용.

핵심 기능 ① — AI (메인)

AI가 취업 준비를 대신 설계한다

01

AI 취업 로드맵

희망 직무 입력 → 2년 4학기 학습 경로 + 추천 자격증(필수/권장/선택) 생성.

02

AI 가상 면접

내 포트폴리오를 분석해 실전 면접 질문 생성 → 답변 피드백·총평.데모 하이라이트

03

AI 자기소개서

회사·직무·소제목 선택 → 맞춤 자소서 초안을 즉시 작성.

04

AI 포트폴리오 분석

GitHub 저장소·파일(PDF/PPTX)을 넣으면 프로젝트를 자동 정리.

05

AI 학생 어드바이저

성적·출결·졸업요건 종합 분석 → 약점 진단 + 맞춤 조언.

06

플래너 · 이력서

주간 학습 계획·성적 예측, 이력서 자동 완성 + PDF 다운로드.

Spotlight

AI 가상 면접

이력서 첨삭을 넘어, 내 프로젝트 기반의 맞춤 면접 연습. 지원 회사·직무를 고르면 AI 면접관이 포트폴리오를 분석해 실전 질문을 던지고, 답변마다 피드백과 종합 총평을 제공합니다.

STEP 1

회사·직무 선택

스크랩한 공고를 고르거나 직접 입력.

STEP 2

맞춤 질문 → 답변

포트폴리오 기반 질문에 채팅으로 답변.

STEP 3

피드백 · 총평

잘한 점·보완점 + 전체 종합 평가, 기록 보관.

핵심 기능 ② — 학업 관리

내 학업을 한눈에

성적 · 학습 분석

과목별 성적·GPA, 학기별 추이 그래프.

출결 관리

출석/지각/결석 집계 + 결석 3회 경고 배너.

졸업요건 확인

영역별 이수 학점 대비 부족분을 진행바로.

수상 내역

교내외 수상 기록을 등급별로 관리.

강의 리뷰

별점·후기, 익명 옵션, 과목 평균 평점.

조기 경보

출석률·성적 위험을 감지해 이메일 알림.

핵심 기능 ③ — 취업 준비

로드맵에서 실전까지

TRACKING

취업 준비 활동 트래킹

자격증·어학·인턴·공모전 등을 상태(예정/진행중/완료)별로 기록하고 유형별 통계로 확인.

JOBS

채용공고 검색

키워드·지역·경력·고용형태로 채용공고를 검색하고 마음에 드는 공고를 스크랩 저장.

CERT

자격증 정보 (Q-Net)

국가기술자격 시험 일정·종목·상세(응시자격·수수료)·전국 시험장소를 조회.

ALERT

채용 알리미

관심 직무·지역·키워드 등록 → 매일 오전 9시 새 공고를 이메일로 발송.
